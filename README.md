
# Крестики-нолики

## Описание проекта
Данный проект представляет собой консольную игру "Крестики-нолики", разработанную на языке программирования C# в рамках практической работы №2.

Игра предназначена для двух игроков, которые по очереди ставят крестики и нолики на игровое поле размером 3x3.

## Цель проекта
Разработка игры с использованием языка C# и освоение системы контроля версий Git и платформы GitHub.

## Функциональность
- Отображение игрового поля 3x3.
- Поочерёдные ходы двух игроков.
- Проверка корректности ввода.
- Запрет на занятие уже заполненных клеток.
- Определение победителя по горизонтали, вертикали и диагонали.
- Определение ничьей.
- Возможность начать новую игру без перезапуска приложения.

## Используемые технологии
- C#
- .NET
- Git
- GitHub

## Правила игры
1. В игре участвуют два игрока.
2. Первый игрок использует крестики (X), второй — нолики (O).
3. Игроки ходят по очереди.
4. Побеждает тот, кто первым соберёт три одинаковых знака в одну линию.
5. Если все клетки заполнены и победителя нет, объявляется ничья.
